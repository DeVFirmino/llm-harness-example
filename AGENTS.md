# AGENTS.md

This repository is a worked example of a harness. Each folder carries its own
instructions and its own state file. Read the folder that matches the task.

- Working through the SQL joins course → read `study/AGENTS.md`, then `study/progress.md`.
- Planning or changing the notes app → read `notes-app/AGENTS.md`, then `notes-app/facts.md`.

Rules that hold everywhere:

- Never invent a fact that is not in a harness file. Say what is missing instead.
- When a correction reveals a missing or wrong rule, propose an update to the file that
  should have carried it, and show the diff before writing.
- Do not commit. The human reviews the diff and commits the approved version.
